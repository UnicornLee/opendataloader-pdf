- `202504171785131172233015158.pdf`：一处结构性变动（含 `<img>` 标签出现）

### 根因
原"幽灵字"判定（退化字形 = 宽 ≤ max(0.4pt, 0.05×字号) 且同行同字有 ≥2pt 宽者）**过宽**：
提取器会把某些"被压窄的合法字"报成窄宽（0.135pt 的 `「`、0.539pt 的 `3`），它们没有同字近邻，
却因行内有别的退化字/重影而被整行触发处理 → 误删。

### 收紧（已落地，单测通过 + 逆向验证旧逻辑会使新用例失败）
1. **行触发门控**：仅当"同一绘制位置对"——同字 + 交叠≥0.7 +（|Δx0|≤max(0.3,0.05×字号) 或 min/ max 宽≤0.6）——
   或"挤压副本"（同字 + 一个退化 + 另一个≥2pt 真实字形 + 间隔≤0.5pt）。去掉原先"只要存在退化字就触发整行"。
2. **第一步删除**只删"挤压副本"（必须紧邻/覆盖一个同字真实字形），不再无差别删所有退化字。
3. 新增回归单测 `testRemoveOverprintedTextChunksKeepsCollapsedWidthCharacterWithoutCopy`
   （`提升「技防」「智控」` 第二个 `「` 仅 0.135pt 宽 → 必须保留）。

## 附錄四（p351）子目录误留「1. 結餘乃摘錄自…」的问题定位（未改代码，待用户批准）

任务：`docs/pdf/200910301782365038553054634.pdf` 解析后，附錄四（p351）下误留一个子目录
`1.     結餘乃摘錄自本通函附錄一第二節載列之截至二零零九年四月三十日止年度本集團之經審核財務資料。`
与原文相邻的 `2. 該備考調整反映本公司以總代價約239,700,000港元收購eCosway之40%股權。代價將以下列方式償付：`
同为正文注释（非目录项），期望两者都被“相邻原则”丢弃。

### 数据事实
- catalog 树：附錄四 = `bookmarks[8]` = p351 rel=1；下一个 L1 兄弟 = 附錄五 = p385 rel=1。
- 真实切片 = T=(351,1) 与 S=(385,1) 之间的全部候选。
- 用户指定的调试入口：`org.opendataloader.pdf.DebugSample1`。

### 根因（已用探针逐候选验证，结论确定）

切片 = `(351,1)` 之后、`(385,1)` 之前的全部候选 → **42 个候选，仅 2 个模板组**：
`#/ARABIC`（32 个）与 `(#)/ARABIC`（10 个）。`#` 组胜出。
注意 `template` 是**归一化模式串**（`#`、`第#章`、`(#)`…），不是字面文本，两条注释同属 `#` 组。

`#/ARABIC` 32 个候选全部是**同一段注释在 p356/p369/p381 重复出现 3 次**（每页一组 1..N）：
- p356: 1..14（len 52..163，fs=9.0）
- p369: 1..12
- p381: 1..6（用户报错的那条 `1.` 在 p381 rel=4）

**根因链条**（关键：句号过滤破坏了相邻对）：
1. Step 1.5 `applyPeriodEndFilter`：32 个中 28 个以 `。` 结尾，少数 4 个**不以**句号结尾
   （p356 val=5、p358 val=7、p369 val=5、p381 val=2）。28/32=87.5% > `PERIOD_FILTER_RATIO`(0.8)，
   于是**丢弃那 4 个非句号项**。
2. 丢弃后 28 个按 value 切成 Step 2 的 run：
   `[1 2 3 4]`、`[6]`、`[8..14]`、`[1 2 3 4]`、`[6..12]`、**`[1]`**、`[3 4 5 6]`。
3. Step 4.5 `isTocLikeGroup`：**逐 run** 判定。除 `[6]`、`[1]` 外全部 true 被丢。
4. Step 4.8 要求首值=1 → `[6]` 被丢、`[1]` 保留；Step 5 取最宽链 → 只剩 `[1]` → 产出 1 个子目录。

**为什么"相邻原则"没生效**：被丢弃的正是 p381 的 `2.`（val=2，不以句号结尾），
它是与 `1.` 构成**同页相邻 related_id（4→5）**的那一半。
句号过滤先把它删掉，`isTocLikeGroup` 就看不到这对相邻项，孤立的 `1.` 变成单元素链而逃过检测。
即：**相邻原则（Step 4.5）本身是对的，失效原因是句号过滤先一步破坏了相邻关系。**

旁证：`isTocLikeGroup(UNFILTERED)=true`（32 个里相邻对远超阈值 14），
若不先跑句号过滤，该模板组会被整体判为目录残留而丢弃 → 子目录为空（符合期望）。
注意 `isTocLikeGroup(AFTER period)=true` 是对过滤后 28 个的**整体**判断，
但 Step 4.5 实际是**逐 run** 判定，逐 run 时 `[1]` 逃过。
