# 2026-09-18

## 悬挂缩进续行被拆成两段（`200711131781638086275024718-12.pdf`）— 已修复

用户现象：该单页文档里这两行应属**同一段**，但被输出成两个 `text` item：

```
text [70.70, 527.66, 524.31, 542.02]  font_size=12.0  "9. 根據完成分派寄發恒基地產股票及寄發現金付款支票與透過中央結算系統作出"
text [93.38, 546.26, 258.03, 559.54]  font_size=12.0  "額外現金分派及股息金額付款"
```

### 定位

- 版面（渲染确认）：`9.` 是**顶格编号行**（x0=70.70、右边界贴版心 524.31），续行**缩进 22.68pt**（≈ `9.  ` 的宽度）→ 典型 **编号 + 悬挂缩进**。
  行距正常：`546.256 - 542.02 = 4.236pt`（加上行高 13.28 ≈ 1.46 × 字号 12）。
- 判据逐条排查（`ParagraphProcessor.prejudgeParagraphs`）：
  - 字号差 `|12-12| >= 2` → 不触发；
  - 对齐：左差 22.68 > 容差 `maxFontSize × ALIGNMENT_PARAM(0.2) = 2.4`、右差 266 → `getAlignment` 返回 **null**，所以 JUSTIFY/LEFT/RIGHT/CENTER 四个 detect 步骤全不认；
  - **关键**：`prejudgeParagraphs` 里那条"段首缩进"判据是
    `prevLastLineLeftX - nextFirstLineLeftX > -5 && ... < MAX_PARAGRAPH_BEGINNING_INDENT(50)`，
    即它只覆盖**首行缩进、续行顶格**的镜像情况；本例是**首行顶格、续行缩进**，表达式为 `-22.68`，`> -5` 不成立 → 不命中 → 落入各步骤的兜底（各自成段）。

### 修复（`ParagraphProcessor`）

1. 新增常量 `HANGING_INDENT_RIGHT_TOLERANCE = 5.0`（判"该行是否填满版心"）。
2. 新增 `private static boolean isHangingIndentContinuation(TextBlock previousBlock, TextBlock nextBlock, double rightX, double margin)`，
   四条判据（全部满足才合并）：
   - `|previousLine.getRightX() - rightX| < 5` —— 前一行**填满版心**（说明是被折行的，不是段末短行/短标题）；
   - `0 < nextLine.getLeftX() - previousLine.getLeftX() <= MAX_PARAGRAPH_BEGINNING_INDENT` —— 续行缩进量在合理范围；
   - `!BulletedParagraphUtils.isLabeledLine(nextLine)` —— 续行不得是编号行（`10.`/`一、` 是新条目的开头）；
   - `margin <= MAX_LINE_SPACING_RATIO(3.0) × fontSize` —— 垂直间距必须是正常行距。
3. 在 `prejudgeParagraphs` 判据链中插到 `hasSeparatorBetween(...)` **之后**、字号差判据之前；
   命中则 `previousBlock.add(nextBlock.getLines())` + `setTextAlignment(LEFT)` + `setHasEndLine(false)`。

### 验证（`200711131781638086275024718-12.pdf`，单页）

- 两行合并为一条：`[70.70, 527.66, 524.31, **559.54**]`（y1 由 542.02 扩到续行底部，文本长度 52）。
- 该页 items **9 → 8**；其余段落（`在發生完成之前提下…` 那段）**未被误并**。
- 合并后该块的 `source_type` 是 **heading**（因首行是 `9.` 编号 + `HeadingProcessor` 判定），不是 `paragraph`；
  如需要它保持 paragraph 类型，要另调 `HeadingProcessor` 的口径。
- 相关单测 **44/44 绿**（ParagraphProcessorTest 2 / FlowchartProcessorTest 12 / ShapeRecognizerTest 22 /
  BarChartProcessorTest 6 / ArrowE2ETest 2）；临时入口 `DebugTmpPage.java` 与 `cp.txt` 已删除并重新编译。

### 遗留

- 这是**新增判据**（此前无任何规则覆盖悬挂缩进），影响面是所有"编号 + 缩进续行"排版的文档，
  建议跑一次 items 层语料回归，重点看 text 行数**减少**的文档（合并）是否都合理。
- `ParagraphProcessorTest` 只有 2 个用例，建议为 `isHangingIndentContinuation` 补单测（正例 + 三个反例：
  前一行非满行 / 续行缩进超限 / 续行是编号行）。
