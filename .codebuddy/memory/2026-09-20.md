# 2026-09-20

## 表格单元格内文本行合并：新增"两端非中英文"边界规则（`JsonWriter`）— 已实现

### 位置
`java/opendataloader-pdf-core/src/main/java/org/opendataloader/pdf/json/JsonWriter.java`
`writeTableBorder` 的 cell 文本装配循环（`currentCellTextLines` 累加处，约 1084-1125 行）。

### 背景（原逻辑）
单元格内每行由 `assembleGroupText` 生成，是否**新起一条**只由两个判据决定：
1. `containsEmbeddedBlock(group)` —— 图片 / 嵌套表格 HTML 独占一条；
2. `nextNewLine` —— **上一行**右端离 `cell.getRightX()` 超过 `MAX_CELL_LINE_RIGHT_GAP(15)` 就认为上一行是段末，本行新起；
   否则视为折行续行，**追加到最后一条**。

### 需求与修改
用户要求：当 **`currentText` 的首字符** 与 **`currentCellTextLines` 最后一条的末字符** *都不是* 中文（CJK 表意文字）或英文字母时，
`newLine` 也应为 `true`（即新起一条，而不是拼接）。理由：数字/标点/符号相邻时基本不可能构成同一句子的折行续行。

实现：
- 在 `boolean newLine = containsEmbeddedBlock(group) || nextNewLine;` 之后加判据，
  条件 `!newLine && !currentCellTextLines.isEmpty()`（后者保证能取到最后一条；`currentText` 此前已判空）。
- 新增私有静态方法 `isChineseOrEnglishLetter(char c)`：`[A-Za-z]` 或 CJK 统一表意文字 `\u4E00`-`\u9FFF` 返回 `true`，
  数字/标点/符号返回 `false`。（core 模块是 **source level 11**，此处无高版本语法。）

### 注意点
- 规则只作用于 `newLine == false`（即未被前两条判据命中的）情况，属于**补充收紧**，
  不会让本来该合并的"中文/英文折行"被拆开（首末字符至少一侧是中英文即不触发）。
- `else if (currentCellTextLines.isEmpty())` 分支行为未变：为空时仍直接加入首条。
- 半角字符未被纳入"英文"范围，全角标点亦不算中文；如需覆盖日文假名/韩文/CJK 扩展区，需扩展 `isChineseOrEnglishLetter`。

### 验证
`mvn -o -q -pl opendataloader-pdf-core compile` 通过（离线、PowerShell 下用 `cd '...\java'; mvn ...`）。

### 更新（同日）：全角标点纳入"中英文语境"
用户确认"全角标点需要纳入"，故：
- 判据方法由 `isChineseOrEnglishLetter` **改名**为 `isChineseOrEnglishContext`（唯一调用点同步更新），
  语义从"字母"扩为"中文/英文语境字符"：
  - `[A-Za-z]`；
  - `\u4E00`-`\u9FFF` CJK 统一表意文字；
  - `\u3000`-`\u303F` CJK 符号与标点（、。〈〉《》「」【】）；
  - `\uFF00`-`\uFFEF` 半角及全角形式（，．！？：；（）￥０-９Ａ-Ｚ）。
- 效果：两侧都是**全角标点**时不再强制新起条目（视为中文语境，允许拼接）。
- Javadoc 里用 `U+4E00` 这种写法而不是 `\u4E00`，因为 Java 会在**注释里也展开 unicode 转义**，
  写 `\u4E00` 会被渲染成汉字"一"，反而看不懂。

**已知未覆盖**（如需要再说）：中文排印常用的弯引号 `“ ” ‘ ’`、破折号 `—`/`——`、省略号 `……`
位于 General Punctuation `\u2000`-`\u206F`，**不在**上述两个块内，目前仍算"非中英文"。

### 更新（同日，第二次）：General Punctuation 弯引号/破折号/省略号也纳入
用户再次确认"需要纳入"，故在 `isChineseOrEnglishContext` 上再追加两个区间：

```java
|| (c >= '\u2010' && c <= '\u201F')   // 连字符/短横/—/― + 弯引号 ‘ ’ ‚ ‛ “ ” „ ‟
|| (c >= '\u2024' && c <= '\u2027')   // 单/双点前导符、省略号 …、连字点
```

**刻意排除** `\u2020`-`\u2023`（† ‡ • ‣）、`\u2016`-`\u2017` 之外的其余 General Punctuation
（U+2030 起：‰ ′ ″ ‹ › 等）——前者是条目符号/项目符号，属"块首标记"而非行内续行字符；
如需 `‰`（财务文档常见）或 `‹ ›`，再单独加区间。

判据最终形态（`JsonWriter.isChineseOrEnglishContext`）：
`[A-Za-z]` + `\u4E00`-`\u9FFF` + `\u3000`-`\u303F` + `\uFF00`-`\uFFEF` + `\u2010`-`\u201F` + `\u2024`-`\u2027`。

编译验证同前：`mvn -o -q -pl opendataloader-pdf-core compile` 通过。
